# ✈️ TripStay

> Plataforma de viagens com busca de voos,
hospedagens e gerenciamento de reservas.

O **TripStay** é um projeto desenvolvido em React com Vite
que simula uma plataforma moderna de viagens, permitindo que
o usuário pesquise voos, escolha hospedagens, visualize detalhes
dos hotéis e gerencie suas reservas.

O projeto foi desenvolvido com foco em **experiência do usuário,
organização de componentes, navegação entre páginas e responsividade**.

## ✨ Funcionalidades

### ✈️ Busca de voos
- Pesquisa de voos de ida e volta ou somente ida
- Seleção de origem e destino
- Seleção de datas
- Quantidade de passageiros
- Classe da viagem
- Troca rápida entre origem e destino
- Resultados de voos simulados
- Seleção de voo

### 🏨 Hospedagens
- Listagem de hotéis
- Cards com informações principais
- Avaliações e quantidade de avaliações
- Localização
- Comodidades
- Preço por noite
- Hotéis em diferentes destinos

### 🔎 Detalhes do hotel
- Galeria de imagens
- Informações completas sobre o hotel
- Comodidades
- Pontos turísticos próximos
- Avaliações
- Seleção de check-in e check-out
- Quantidade de hóspedes
- Cálculo automático das noites
- Cálculo do valor total da hospedagem

### ❤️ Favoritos
- Adição de hotéis aos favoritos
- Remoção de hotéis dos favoritos
- Página exclusiva de favoritos

### 💰 Ofertas
- Ofertas de voos
- Ofertas de hospedagens
- Valores promocionais
- Percentual de desconto

### 📋 Reservas
- Visualização das reservas realizadas
- Reservas de hospedagem
- Reservas completas com voo + hotel
- Informações da viagem
- Valores totais
- Cancelamento de reservas
- Confirmação de reserva através de modal

### 🧳 Resumo da viagem
- Seleção de voo e hotel
- Cálculo do valor do voo
- Cálculo das diárias
- Cálculo do valor total da viagem
- Confirmação da reserva

### 📱 Responsividade
- Layout adaptado para desktop
- Layout adaptado para dispositivos móveis
- Menu mobile
- Interface responsiva para diferentes tamanhos de tela
